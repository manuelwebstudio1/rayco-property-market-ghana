# Rayco Property Market Ghana Limited

Premium real-estate website for **Rayco Property Market Ghana Limited** — a Ghanaian broker and official estate agent serving local and multinational clients.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Listings, testimonials, blog posts and images live in `/data`. Swap those files to update live inventory without touching layout components.
